Unity Editor 清理順序（目前尚未執行）
1. 開啟 Assets/Resources/CoreManager.prefab。
   移除原 MinigameManager 元件（刪除程式後可能顯示 Missing Script）。
   只移除該元件，保留 CoreManager 物件及其他核心元件。
   BootstrapSceneLoader 仍需載入 CoreManager，因此不修改載入器。
2. 下列舊場景 / Prefab 若不再使用，可在 Editor 刪除。
   若仍保留某個資產，移除退役元件與對應 FSM Action、Call Method、
   Object / Enum 型別變數、UnityEvent 呼叫及等待舊完成事件的步驟。
   包括 ContinueToNextMinigameAction / OverrideReturnScene，以及
   MinigameEndReason、PlayMakerMinigameAdapter_Multi2、舊結算與 Slider 演出。
   確認 Build Settings 與仍使用的場景不再指向這些舊資產。
3. 刪除 Assets/Resources/Minigame/MinigameEndReasonNormal.asset。
   它是已移除 MinigameEndReasonConfig 的專用舊設定。
4. 由 Unity 處理刪除腳本留下的 .meta，並檢查版本控制中的相應變更。
   本次未手動改動任何 .meta、場景、Prefab、ScriptableObject 或 FSM。
   未清理的舊資產可能出現 Missing Script / 失效型別，應移除殘留參照。
